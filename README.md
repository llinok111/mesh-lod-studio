# mesh-lod-studio

A quadric-error (QEM) mesh decimation workbench with a browser studio and a node-verifiable
accuracy contract. No build step, no `node_modules`, no headless browser.

**The promise:** a 24,320-triangle sphere decimates to **2,432 triangles (10%)** with a
**maximum surface error of 0.069% of the bounding-box diagonal**, stays a **closed manifold**
(Euler characteristic 2, zero boundary/non-manifold edges), in **381 ms median** — and those
same numbers are asserted by `node bench/verify.mjs`.

## Run it

```bash
python3 -m http.server 4173
# open http://localhost:4173
```

The page pulls `three@0.169.0` from jsDelivr via an import map. Nothing to install.

```bash
node bench/verify.mjs   # 28 hard assertions, exits 0 only if all pass
node bench/bench.mjs    # 5 repeats per mesh, median written to bench/result.json
```

## Measured results

10% triangle budget, median of 5 runs, Node v24.19.0 on AMD EPYC 7K62 (4 vCPU container).
Exact machine-readable output: [`bench/result.json`](bench/result.json).

| mesh | triangles in → out | reduction | median | max error (% diag) | mean error (% diag) | topology |
|---|---|---:|---:|---:|---:|---|
| sphere (closed) | 24,320 → 2,432 | 90.0% | 381 ms | 0.069% | 0.020% | closed, Euler 2, volume −0.17% |
| torus (closed) | 12,288 → 1,228 | 90.0% | 200 ms | 0.238% | 0.047% | closed, Euler 0 (genus 1) |
| terrain (open) | 28,800 → 2,880 | 90.0% | 567 ms | 0.441% | 0.063% | open, 198 boundary edges, 0 non-manifold |

Error is symmetric surface deviation, sampled area-weighted on both meshes and expressed as a
percentage of the source bounding-box diagonal. It is not vertex distance: the metric samples
points anywhere on the surface, including triangle interiors.

## What the core actually does

`src/core.mjs` is dependency-free ES module code (no three.js, no DOM, no Node APIs), so the
browser and the test runner execute the identical implementation.

1. **Weld / index repair** — spatial-hash merge of coincident vertices, removal of degenerate
   triangles and duplicate faces, with exact counters.
2. **QEM decimation** — area-weighted plane quadrics per vertex, boundary constraint quadrics,
   optimal contraction point from the 3×3 quadric system (endpoints and midpoint are also
   evaluated, so a collapse never costs more than an endpoint collapse), a min-heap with lazy
   version invalidation, link-condition checks, duplicate-face rejection and a per-face normal
   flip guard.
3. **Topology** — edge incidence counts, boundary and non-manifold edges, connected components,
   Euler characteristic, signed enclosed volume.
4. **Deviation** — area-weighted deterministic surface sampling plus a uniform AABB triangle
   grid with conservative ring expansion. The grid is cross-checked against brute-force
   point–triangle distance in the test suite (observed difference: exactly 0).

## Why the numbers are trustworthy

- **Deterministic:** seeded sampling and a stable heap tie-break. The same input produces
  bit-identical positions and indices (asserted by FNV-1a hash).
- **Fixtures with known defects:** the weld test injects 2 duplicate vertices, 1 degenerate
  triangle and 1 duplicate face, then asserts the exact repair counters.
- **Topology, not vibes:** the sphere must remain closed with Euler 2; the torus must keep
  Euler 0; the terrain must keep a boundary while gaining no non-manifold edges.
- **Metric validated independently:** 150 sampled distances from the AABB grid are compared
  with brute-force triangle distance; the max difference must be `< 1e-9`.
- **Performance is measured:** 5 repetitions, median reported; `bench/result.json` records
  min/max and machine info so the number is reproducible rather than quoted.

## Browser studio

- Three procedural sources: UV sphere, torus, noise terrain (generated by the same core).
- Side-by-side source vs. LOD, orbit/zoom/pan, wireframe and auto-rotate toggles.
- Per-vertex deviation heatmap, computed against the original surface.
- Live readout of triangles, reduction, decimation time, symmetric max/mean error, volume
  drift, Euler characteristic and manifold status.
- Export the current LOD as `.obj` with a header containing its measured error.

The UI intentionally computes 1,200 deviation samples per interaction for responsiveness;
the node benchmark uses 3,000. Topology and triangle counts are identical in both.

## Use the core directly

```js
import { generateSphere, decimate, analyzeTopology, measureDeviation } from './src/core.mjs';

const src = generateSphere(128, 96);                  // 24,320 tris
const lod = decimate(src, { targetRatio: 0.1 });      // 2,432 tris
const topo = analyzeTopology(lod);                    // { closed: true, euler: 2, ... }
const err = measureDeviation(src, lod, { samples: 3000 });
console.log(lod.stats.outputTriangles, err.maxPct);   // 2432 0.0687...
```

## Limits

- Geometry only: UVs, skinning, morph targets and materials are not carried through.
- QEM is a heuristic; the reported error is empirical and sampling-based, not a formal bound.
- Single-threaded: ~0.5 s for 24k triangles on this container. Very large scans would need
  spatial partitioning of the collapse queue.
- The terrain is open, so signed volume is displayed as `n/a` rather than a misleading number.
